El caso de estudio

Un pequeño negocio quiere lanzar una zapatería online con estética victoriana. El equipo está desarrollando un tema de WordPress y un plugin complementario para WooCommerce en un entorno local con XAMPP. Durante las pruebas, el equipo descubre que MariaDB no inicia, por lo que WordPress no puede conectarse a la base de datos y el equipo no puede continuar las pruebas de la tienda.

Datos observados: XAMPP no consigue iniciar MariaDB; el cliente MySQL devuelve un error de conexión ERROR 2002 (HY000): Can't connect to MySQL server on 'localhost' (10061); los registros y las herramientas de diagnóstico apuntan a un posible problema en la tabla del sistema mysql.global_priv y su índice Aria. No se debe asumir que el primer mensaje de error ya identifica la causa raíz.

Tu tarea es proponer un abordaje metódico, distinguir síntomas de causas y definir cómo el equipo verificará la solución.
